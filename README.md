## Как использовать

1. Замените все изображения в папках `img/`, `img/icons/` и `img/auditors/` на реальные фото и иконки
2. Обновите информацию о контактах в секции "Contact"
3. Откройте `index.html` в браузере
4. Используйте CSS для дополнительных настроек стилей

## Функциональность

- Плавный скролл при клике на навигацию
- Анимация элементов при появлении на экране
- Кнопка "Вверх" появляется при прокрутке более чем на 400px
- Форма обратной связи (требует backend для отправки)
- Мобильное меню (burger menu - требует JavaScript)
