# A&Z Audit Consulting — сайт компании

Сайт аудиторской компании A&Z Audit Consulting, Алматы. Чистый HTML/CSS/JS, без фреймворков и сборщиков.

## Что внутри

50 страниц на русском и английском, под казахстанский рынок:

- **Услуги** — аудит, бухгалтерский аутсорсинг, налоговый консалтинг, восстановление учёта, МСФО и другие
- **Блог** — 24 статьи по аудиту, налогам и бухгалтерии
- **Кейсы** — 6 реальных проектов с описанием задачи и результата
- **О компании, команда, лицензии, отзывы, контакты**

```
├── index.html
├── css/style.css
├── img/
├── blog/          # 24 статьи
├── cases/         # 6 кейсов
└── [страницы услуг].html
```

## Технологии

- Верстка — чистый HTML5/CSS3, адаптив под мобильные
- Шрифты — Inter, Poppins (Google Fonts)
- Аналитика — Google Analytics 4 (G-J1381WXN0H)
- Реклама — Google Ads, отслеживание конверсий
- Форма заявки — EmailJS, без бэкенда
- WhatsApp — плавающая кнопка + отслеживание кликов через GA4

## Отслеживание событий

Форма заявки отправляет события `generate_lead` и `close_convert_lead` в GA4 и Google Ads при успешной отправке.

Клик по WhatsApp — событие `whatsapp_click`. Используется делегирование через `document.addEventListener('click')` с `e.target.closest()`, чтобы ловить и обычные ссылки, и плавающую кнопку `.wa-float`. Добавлена защита `typeof gtag === 'function'` на случай, если GA4 заблокирован расширением.
